# Nenolink AI Marker 1.0.3 — implementation status

Last updated: 2026-09-24
Branch: `feature/1.0.3-document-types`

## Completed

- Added shared, frozen processing contracts for disclosure, logo, output,
  capability reporting, source protection and one-based page/slide selection.
- Added a compact localized content workspace selector directly below the
  existing header for Images, Video, PDF, PowerPoint/Slides and Word.
- Preserved independent image/video selections while navigating workspaces.
- Added all new shell strings to all 12 existing UI locales.
- Added a targeted `.pptx` Open Packaging Convention processor without
  `python-pptx`, so unrelated package parts and unsupported PowerPoint content
  are not reconstructed by a high-level library.
- PPTX supports one slide, non-contiguous selected slides, ranges and the full
  presentation.
- PPTX supports independently positioned/sized/margined/transparent AI badge
  and optional company logo overlays.
- PPTX output is written through a temporary file to a distinct destination;
  the source is never overwritten.
- Added privacy-safe PPTX custom properties for the disclosure label, output
  language, application/version and Nenolink marker identifier, plus a
  read-only metadata round-trip helper.
- Covered Unicode paths and disclosure labels.

## DOCX completion checkpoint — 2026-09-24

- Added safe `.docx` whole-document marking through targeted OOXML package
  patches. Existing body content, styles, tables, images, sections and
  unrelated package parts are retained; source documents are never replaced.
- AI badge and optional Own Logo can be added independently or together as
  floating, page-relative header/footer drawings with shared position, size,
  margin and opacity settings. Existing headers and footers are cloned before
  augmentation so their content is preserved.
- Added a lightweight representative-page preview. It is deliberately labelled
  approximate because DOCX pagination depends on Word, fonts and the active
  renderer; page-specific selection is not offered.
- Added privacy-safe AI Marker custom-property metadata, metadata round-trip
  and Inspect File support while preserving unrelated custom/core metadata.
- Added centralized DOCX limits: warning above 50 MB and hard stop above
  200 MB. No page-count limit is claimed because reliable pagination requires
  a Word-compatible layout engine.
- Added Word workspace strings in all 12 UI languages plus targeted coverage
  for ordinary text, multiple sections, existing images/tables/headers/footers,
  badge/logo combinations, Unicode paths, source protection, limits, metadata
  and reopening generated DOCX files.
- Targeted DOCX/shared/PDF/PPTX/localisation tests: `86 passed`.
- A realistic two-section output reopened successfully with its table, image,
  text and existing core metadata intact. PNG render QA could not run because
  the required bundled LibreOffice executable is absent from the current
  workspace dependency runtime; no user-installed Office renderer was used.
- Technical limitation: visible markings are whole-document header/footer
  overlays. Arbitrary Word-page or section selection is intentionally not

- Next task: manual DOCX verification and later 1.0.3 packaging review. Do not

## DOCX production UI withdrawal — 2026-09-24

- DOCX support was investigated and implemented experimentally, including its
  processor, preview, metadata, limits, localisation and regression coverage.
- Repeated manual testing found that generated markings were not displayed
  reliably in Microsoft Word, even when other office software displayed them
  and the generated OOXML validated correctly. Because Microsoft Word is the
  primary compatibility requirement, Word/DOCX is not a supported 1.0.3
  production format.
- Removed Word from the production format navigation. The visible 1.0.3 format
  choices are now Images and Video under MEDIA, and PDF and PowerPoint / Slides
  under DOCUMENTS. No empty navigation width is reserved for Word.
- The experimental DOCX implementation and its tests remain in the branch for
  possible future research; they are not reachable from the normal 1.0.3 UI.
- Moved the MEDIA/DOCUMENTS selector two pixels downward and removed the
  three-pixel top gap above the workspace tab navigation so both compact groups
  align more closely with the upper boundary of the main workspace.
- Targeted UI/navigation, localisation, Images/Video navigation and PDF/PPTX
  document-workspace regressions: `98 passed`. The full suite and Windows
  packaging were intentionally not run.
