# Nenolink AI Marker 1.0.3 — implementation status

Last updated: 2026-09-19
Branch: `feature/1.0.3-document-types`

## Completed

- Added shared, frozen processing contracts for disclosure, logo, output,
  capability reporting, source protection and one-based page/slide selection.
- Added a compact localized content workspace selector directly below the
  existing header for Images, Video, PDF, PowerPoint/Slides and Word.
- Preserved independent image/video selections while navigating workspaces.
- Added all new shell strings to all 12 existing UI locales.
- Added a targeted `.pptx` Open Packaging Convention processor without
  `python-pptx`, so unrelated package parts and unsupported PowerPoint content
  are not reconstructed by a high-level library.
- PPTX supports one slide, non-contiguous selected slides, ranges and the full
  presentation.
- PPTX supports independently positioned/sized/margined/transparent AI badge
  and optional company logo overlays.
- PPTX output is written through a temporary file to a distinct destination;
  the source is never overwritten.
- Added privacy-safe PPTX custom properties for the disclosure label, output
  language, application/version and Nenolink marker identifier, plus a
  read-only metadata round-trip helper.
- Covered Unicode paths and disclosure labels.

- PPTX preview is deliberately a lightweight placement/scale guide, not a full
  PowerPoint renderer.

- PDF and DOCX processing have not started.

  environment issue already observed before the PPTX work, not a processor-test
  failure.
